# System Formy

Responsive React + TypeScript + Vite frontend starter.

## Development

Requires Node.js 22 or newer.

1. Run `npm install`.
2. Run `npm run dev`.

## Build

Run `npm run build`.

## Current status

This starter includes a responsive landing page and challenge previews.

Authentication, database, payments, admin tools, paid downloads,
progress tracking, and custom training plans are not connected yet.
